# Rayyan Oumlil

Computer science student at Université de Montréal (graduating April 2027), building AI governance tooling and market/risk software.

## What I work on

- **LLM infrastructure:** gateways, policy, audit trails and MCP tool control for organizations that have to prove what their AI did.
- **Quantitative finance:** options pricing, risk metrics and paper-trading systems, with results that can be reproduced.
- **Multi-agent systems:** agents with real data and real tools (customer support, regulatory analysis, health-care triage).
